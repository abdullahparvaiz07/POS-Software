# Restaurant POS Monorepo

This repository contains the full-stack Restaurant POS application.



## Project Structure

- `client/` - Frontend React application (Vite + TypeScript)
- `server/` - Backend services (coming soon)
- `docs/` - Project documentation
- `database/` - Database configurations and migrations

## Run Locally

**Prerequisites:**  Node.js

### Frontend (Client)

1. Navigate to the client directory:
   `cd client`
2. Install dependencies:
   `npm install`
3. Set the `GEMINI_API_KEY` in `client/.env.local` to your Gemini API key
4. Run the app:
   `npm run dev`
